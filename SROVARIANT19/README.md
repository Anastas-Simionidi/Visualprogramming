# SRO Variant 19 — Food Nutrition Calculator

Мини-проект по дисциплине «Визуальное программирование».
Тема: Калькулятор питания (Food Nutrition Calculator).
Выполнил: Симиониди Анастас
Курс: 3
Группа: ИС 24-22

## Технологии
* Java 17+
* JavaFX 21
* FXML / Scene Builder
* Maven

## Как запустить
1. Склонируйте репозиторий.
2. Откройте проект в IntelliJ IDEA.
3. Запустите файл `Launcher.java` (класс `com.example.srovariant19.Launcher`).
   *Или через терминал командой:* `mvn clean javafx:run`

## Функционал
* Добавление, редактирование и удаление продуктов.
* Поиск по названию и фильтрация по категориям.
* Автоматический подсчёт КБЖУ (калории, белки, жиры, углеводы) с учётом веса порции.
* Валидация ввода и обработка ошибок.
* Горячие клавиши (Ctrl+N, Ctrl+F, Delete и др.).
